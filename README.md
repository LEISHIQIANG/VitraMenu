# VitraMenu

Windows 右键菜单增强工具，为文件资源管理器添加实用功能。

## 功能列表

| 英文名称 | 中文名称 | 说明 | 适用范围 |
|---------|---------|------|----------|
| Copy File Path | 复制文件路径 | 复制完整路径到剪贴板 | 文件 & 文件夹 |
| Unlock Item | 解锁文件 | 查找并终止占用文件的进程（需 handle64.exe） | 文件 & 文件夹 |
| Unpack Folder | 解包文件夹 | 将文件夹内容移动到上级目录 | 文件夹 |
| Quick Rename | 快速重命名 | 添加日期前缀或后缀（YYYY_MM_DD） | 文件 & 文件夹 |
| Convert Encoding | 转换编码 | 转换文本编码（UTF-8 / ANSI / UTF-16） | 文件 |
| File Hash | 文件哈希 | 计算 MD5 / SHA-1 / SHA-256 并复制 | 文件 |
| Take Ownership | 获取所有权 | 获取所有权并授予完全控制（需管理员） | 文件 & 文件夹 |
| Clear Read-only | 清除只读属性 | 清除只读属性 | 文件 & 文件夹 |
| Super Delete | 超级删除 | 使用 Git Bash 强制删除（需 Git for Windows） | 文件 & 文件夹 |
| Firewall Rules | 防火墙规则 | 设置防火墙入站/出站规则（需管理员） | .exe 文件 |
| Create Date Folder | 创建日期文件夹 | 创建以今日日期命名的文件夹（格式：YYYY_MM_DD） | 文件夹背景 |
| Extract Structure | 提取目录结构 | 将目录树结构导出为 .txt | 文件夹 |
| Extract All Files | 提取所有文件 | 将子文件夹中的文件平铺到当前目录 | 文件夹 |
| Clean Empty Folders | 清理空文件夹 | 递归删除所有空文件夹 | 文件夹 |
| Claude Code | Claude Code | 在当前目录启动 Claude Code | 文件夹背景 |
| Codex | Codex | 在当前目录启动 Codex | 文件夹背景 |
| Restart Explorer | 重启资源管理器 | 重启 Windows 资源管理器 | 文件夹背景 |
| Flush DNS Cache | 刷新 DNS 缓存 | 清除 DNS 缓存 | 文件夹背景 |
| Open Registry Editor | 打开注册表编辑器 | 以管理员身份打开注册表编辑器 | 文件夹背景 |
| Open Hosts | 打开 Hosts 文件 | 以管理员权限编辑 hosts 文件 | 文件夹背景 |
| Clear Icon Cache | 清理图标缓存 | 清除 Windows 图标缓存 | 文件夹背景 |
| Pin to Start Menu | 固定到开始菜单 | 添加到开始菜单 | .exe / .lnk |
| Disk Cleanup | 磁盘清理 | 打开磁盘清理工具 | 驱动器 |
